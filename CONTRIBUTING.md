# Cómo colaborar

Sigue estos pasos para colaborar en el proyecto.

## Preparar el entorno

1. Instala PHP 8.2 o superior.
2. Clona el repositorio.
3. Arranca el servidor con `php -S localhost:8000`.
4. (Opcional) Instala Node.js y ejecuta `npx markdownlint-cli2 "**/*.md"` para comprobar los archivos Markdown.

## Ramas y commits

Crea una rama por cada cambio, con un nombre claro:

- `feature/nombre-de-la-mejora`
- `fix/nombre-del-error`
- `docs/nombre-del-cambio`

Escribe los mensajes de commit en español, en presente y cortos. Por ejemplo:

```text
Corrige el comando de ejecución en el README
```

## Abrir una Pull Request

1. Sube tu rama al repositorio.
2. Abre una Pull Request hacia la rama principal.
3. Explica qué has cambiado y por qué.
4. Espera la revisión y corrige lo que se pida.
